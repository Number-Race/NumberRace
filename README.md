<h2 align = "left"></h2>

`Number Race` is a **terminal** game project to play inside Termux
<h2 align="left">Introduction</h2>

- The game was made fully on **Python**. Other like **C#**, **Lua** or either **Ruby** are might be soon!
- No pips
- Closed Source *unfortunately*..
<h2 align="left">Features</h2>

- Some few main gamemodes like **PvE** and **Endless**. Inside there few **Minimodes** like *Duel*, *Duo* and etc
- The *account system* and **Statistic**
- A ton of options in **Settings**
- And much few more!
<h2 align="left">Installation</h2>

1. Download **Termux** from [Github](https://github.com/termux/termux-app/releases) (*recommended*),  [Google Play](https://play.google.com/store/apps/details?id=com.termux) or [F-Droid](https://f-droid.org/en/packages/com.termux/)
2. Copy this command
```bash
curl -fsSL https://raw.githubusercontent.com/Crex56/NumberRace/refs/heads/main/install | bash
```
