<h2 align = "left"></h2>

`Number Race` is a game project to play inside Termux on Android
<h2 align = "left">Installation</h2>

1. Download **Termux** from [Github](https://github.com/termux/termux-app/releases) (*recommended*),  [Google Play](https://play.google.com/store/apps/details?id=com.termux) or [F-Droid](https://f-droid.org/en/packages/com.termux/)
2. Copy this command
```bash
curl -fsSL https://raw.githubusercontent.com/Crex56/NumberRace/refs/heads/main/install | bash
```
